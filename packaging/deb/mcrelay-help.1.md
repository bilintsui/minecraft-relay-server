# NAME

mcrelay-help - display help for mcrelay commands

# SYNOPSIS

**mcrelay help** [_command_]

# DESCRIPTION

Display general help, or the help for the specific _command_ when one is given.

The available commands are **dumpconfig**, **run**, **version** and **help**.

# EXAMPLES

**mcrelay help**
: Show general help.

**mcrelay help run**
: Show help for the **run** command.
