# NAME

mcrelay-version - print the mcrelay version

# SYNOPSIS

**mcrelay version**

# DESCRIPTION

Print the installed **mcrelay** version in a single line, in the form
`v<display>(<internal>)`, for example `v1.2-beta7(69)`.
